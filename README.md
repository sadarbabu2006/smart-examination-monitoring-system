# ExamGuard

ExamGuard is a Smart Examination Monitoring platform designed to provide a secure, fair, and reliable environment for online examinations.

The platform manages the complete candidate-side examination workflow, including candidate registration, authentication, registration photo verification, dashboard management, system readiness checks, examination instructions, monitoring, session management, and result reporting.

## Key Features

- Candidate Registration and Login
- Registration Photo / Identity Baseline
- Secure Candidate Authentication
- Candidate Dashboard
- System Readiness Checks
- Camera Availability Verification
- Browser Compatibility Check
- Internet Connectivity Check
- Examination Instructions
- Examination Session Management
- Proctoring and Integrity Monitoring
- Suspicious Activity Detection
- Face Presence Monitoring
- Examination Results and Reporting
- Candidate Profile Management

## Technology Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite
- OpenCV
- Pytest

## Project Goal

The goal of ExamGuard is to create a reliable online examination environment where candidate identity, examination readiness, monitoring data, and examination integrity can be managed through a unified platform.
