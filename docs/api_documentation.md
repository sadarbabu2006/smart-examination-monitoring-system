# API Documentation

## REST Endpoints Specification

### Authentication
- `POST /api/auth/login`
- `POST /api/auth/register`

### Exam Sessions
- `POST /api/exams/session/start`
- `POST /api/exams/session/submit`
- `GET /api/exams/session/<session_id>`

### Monitoring & Telemetry
- `POST /api/monitoring/events`
- `GET /api/monitoring/events/<session_id>`

### Integrity & Reports (Proctor / Administrator Audit)
> **Architecture Note**: Integrity scoring is generated by the backend during exam submission. It is used for proctoring and institutional audit. Candidate-facing Results are reserved for academic examination outcomes.

- `GET /api/exam-sessions/<session_id>/integrity`: Administrative/Proctor endpoint to retrieve computed integrity score, risk classification, face presence ratio, and transparent deduction breakdown for institutional audit.
- `GET /api/reports/<session_id>`: Examination session report.
- `POST /api/reports/generate`: Generate formal proctoring audit report.

### Candidate Academic Results
- `GET /api/exam-sessions`: Candidate endpoint listing scheduled and completed examination sessions. Returns academic session metadata (`id`, `exam_identifier`, `status`, `started_at`, `ended_at`, `created_at`) without exposing proctoring surveillance telemetry.
- `GET /api/exam-sessions/<session_id>`: Candidate endpoint for single session academic details.

### Proctor & Administrator Authentication
- `POST /api/admin/auth/login`: Authenticates an institutional proctor or administrator (`email`, `password`). Sets isolated admin session.
- `POST /api/admin/auth/logout`: Terminates current proctor/administrator session.
- `GET /api/admin/auth/me`: Retrieves authenticated administrative profile and role.

### Proctor & Administrator Dashboard & Audit
- `GET /api/admin/dashboard/summary`: Live summary counts (`active_sessions`, `submitted_sessions`, `high_risk_sessions`, `total_sessions`). Requires `PROCTOR` or `ADMIN` role.
- `GET /api/admin/sessions`: List of monitored examination sessions prioritized by integrity risk level (`HIGH` > `MEDIUM` > `LOW` > `Active`). Requires `PROCTOR` or `ADMIN` role.
- `GET /api/admin/sessions/<session_id>`: Comprehensive examination audit record with proctoring events, absence intervals, and deterministic deduction breakdown. Requires `PROCTOR` or `ADMIN` role.

### Role Definitions & Access Control
- **CANDIDATE**: Accesses candidate portal (`/dashboard`, `/login`, `/exam`). Reserved for taking exams and viewing academic results. Cannot access administrative endpoints.
- **PROCTOR**: Institutional proctor accessing `/admin`. Authorized to view live examination telemetry, session statuses, and integrity scores.
- **ADMIN**: Institutional administrator with comprehensive administrative and proctoring oversight.

### Evidence
- `GET /api/evidence/<event_id>`
- `POST /api/evidence/upload`
